# Guided Lab 386.5.2 – Matplotlib Pyplot Markers and Line Styles

## Overview

This lab introduces the use of markers and line styles in Matplotlib to enhance data visualizations. It demonstrates how to highlight data points with different marker shapes, customize line styles, and independently modify marker appearance.

## Objectives

* Apply markers to highlight data points
* Use different line styles in line plots
* Customize marker colors and appearance
* Create clear and visually appealing line charts

## Technologies Used

* Python 3
* Matplotlib
* NumPy
* Google Colab / Jupyter Notebook

## Methods & Concepts

* `np.array()` – Create arrays for plotting data
* `plt.plot()` – Create a line plot
* `marker` – Specify the shape used for each data point
* `linestyle` – Define the appearance of the line
* `color` – Set the line color
* `markerfacecolor` – Set the fill color of markers
* `markeredgewidth` – Set the width of the marker border
* `plt.show()` – Display the completed visualization

## Common Marker Styles

| Marker | Description    |
| ------ | -------------- |
| `o`    | Circle         |
| `D`    | Diamond        |
| `d`    | Thin Diamond   |
| `s`    | Square         |
| `>`    | Triangle Right |
| `^`    | Triangle Up    |
| `v`    | Triangle Down  |
| `*`    | Star           |
| `+`    | Plus           |
| `x`    | X              |

## Common Line Styles

| Style    | Code              |
| -------- | ----------------- |
| Solid    | `-` or `solid`    |
| Dashed   | `--` or `dashed`  |
| Dash-dot | `-.` or `dashdot` |
| Dotted   | `:` or `dotted`   |
